Two metric details matter. First, the official protocol's “recording-macro RMSE” equals its macro MAE here because there is only one HR error per recording; each recording's one-sample RMSE is simply its absolute error. The pooled RMSE is therefore the more recognizable global RMSE for the official results.

Second, I would not report reported_rmse_plus_minus_official_formula as an RMSE uncertainty. As you noted, it is derived from the standard error of the squared errors. It can be retained only if clearly labeled as the statistic used by the original official implementation, not as “RMSE ± standard error.”


2. Intra-dataset versus cross-dataset behavior
There is a clear directional asymmetry.

For a PURE target, switching from PURE-trained intra evaluation to the UBFC-trained cross model increases recording-macro MAE substantially:

| Protocol | PURE intra | UBFC→PURE cross | Cross/intra |
| -------- | ---------: | --------------: | ----------: |
| official |      0.405 |           1.986 |   **4.90×** |
| old      |      1.113 |           4.161 |   **3.74×** |
| PRISM    |      0.910 |           4.734 |   **5.20×** |



For a UBFC target, PURE→UBFC is much more stable:
| Protocol | UBFC intra | PURE→UBFC cross | Cross/intra |
| -------- | ---------: | --------------: | ----------: |
| official |      0.630 |           0.952 |       1.51× |
| old      |      0.870 |           0.949 |       1.09× |
| PRISM    |      1.037 |           0.935 |       0.90× |


The PRISM cross value being slightly below the UBFC-intra value should not be read as cross-domain training improving performance. The intra evaluation contains only 12 held-out UBFC recordings, whereas cross uses all 42 UBFC recordings; the checkpoint and evaluation populations are different.

The defensible conclusion is therefore: these runs show much stronger degradation for UBFC→PURE than for PURE→UBFC, consistently across the three evaluation procedures. It is not a clean causal estimate of the domain gap because the target recording sets are not matched.

The waveform correlations support this directional pattern as well. PURE→UBFC official retains a mean waveform correlation of 0.823, close to UBFC-intra's 0.842. UBFC→PURE falls to 0.572 versus 0.636 for PURE intra.




3. Protocol sensitivity
The biggest finding is that protocol sensitivity itself depends strongly on the experiment.

PURE_INTRA: macro MAE ranges from 0.405 to 1.113 BPM, a 2.75× span. The complete-recording official calculation is substantially less affected by transient local spectral mistakes than the short-window calculations. Old is particularly affected by occasional catastrophic harmonic windows despite most windows being exactly correct on its 7.5-BPM grid.

UBFC_INTRA: macro MAE ranges from 0.630 to 1.037 BPM. The apparent PRISM degradation is disproportionately influenced by a single 10-second failure in subject41; its recording MAE becomes 6.006 BPM even though the other five windows are good.

PURE→UBFC CROSS: this is remarkably stable in the primary metric: 0.935–0.952 BPM, only a 0.016-BPM range. This is strong evidence that the headline recording-average error for this checkpoint is not especially dependent on these three particular HR extraction procedures. The tail statistics still vary: pooled RMSE is 1.826 official, 3.249 old, and 2.666 PRISM.

UBFC→PURE CROSS: this is highly protocol-sensitive: 1.986 official versus 4.161 old and 4.734 PRISM. Here short-window evaluation repeatedly encounters harmonic or gross local errors that a single full-record spectrum can sometimes suppress.

The old and PRISM protocols also tend to identify the same difficult recordings in the problematic cross run: their recording-level MAE correlation for UBFC→PURE is about 0.856. By contrast, official versus old is only about 0.254. In PURE→UBFC, official recording MAE is essentially uncorrelated with old/PRISM recording MAE, while old versus PRISM correlates about 0.666. That is a concrete demonstration that “which recording is worst” can itself depend on the aggregation rule.

There is also a resolution effect. The old protocol's direct 240-point FFT constrains errors to the 7.5-BPM grid: its observed absolute errors are 0, 7.5, 15, 22.5, 30 BPM, etc. PRISM's zero-padded grid allows much finer HR values, while official Welch produces roughly 0.540-BPM frequency spacing in these outputs. This changes both the error distribution and the interpretation of small errors.
